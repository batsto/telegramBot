## Описание проекта
Этот телеграм-бот предназначен для поиска фильмов и сериалов по различным критериям. Он взаимодействует с API фильмов и позволяет пользователям выполнять следующие команды:

- **`/movie_search`**: Поиск фильма/сериала по названию.
- **`/movie_by_rating`**: Поиск фильмов/сериалов по рейтингу.
- **`/low_budget_movie`**: Поиск фильмов/сериалов с низким бюджетом.
- **`/high_budget_movie`**: Поиск фильмов/сериалов с высоким бюджетом.
- **`/history`**: Просмотр истории запросов.

## Требования для запуска

1. **Python**: Проект написан на Python и требует версии не ниже 3.9.
2. **Библиотеки**: Для запуска бота необходимо установить следующие библиотеки:
    ```
   pip install python-telegram-bot peewee requests
    ```
3. **API ключи**: Необходимо получить API ключи для взаимодействия с API фильмов и Telegram Bot API.

## Установка и запуск

1. **Клонирование репозитория**:
```
git clone https://gitlab.skillbox.ru/mishania_geniush/python_basic_diploma.git
```
2. **Установка зависимостей**:
```
pip install -r requirements.txt
```
3. **Настройка API ключей**:
- Создайте файл `.env` в корне проекта и добавьте туда свои API ключи:
  ```
  TELEGRAM_API_TOKEN=ваш_токен_телеграм_бота
  MOVIE_API_KEY=ваш_ключ_API_фильмов
  ```
4. **Запуск бота**:
```
python main.py
```

## Команды бота

- **`/help`**: Вывод справки по доступным командам.
- **`/movie_search`**: Поиск фильма/сериала по названию.
- Пример: `/movie_search "Название фильма"`
- **`/movie_by_rating`**: Поиск фильмов/сериалов по рейтингу.
- Пример: `/movie_by_rating 8`
- **`/low_budget_movie`**: Поиск фильмов/сериалов с низким бюджетом.
- **`/high_budget_movie`**: Поиск фильмов/сериалов с высоким бюджетом.
- **`/history`**: Просмотр истории запросов.

## История запросов

При запросе истории бот выводит дату поиска, название фильма/сериала, описание, рейтинг, год производства, жанр, возрастной рейтинг и постер.

## Дополнительные возможности

- **Пагинация**: Вывод информации о фильмах/сериалах реализован через пагинацию.
- **Отметка просмотренных**: В истории поиска доступны кнопки для отметки просмотренных и непросмотренных фильмов и сериалов.
